# 测试边界表（test-boundaries）

明确每层测什么、mock 到哪一层为止、哪些必须真实连接。验收时按此表核对证据层级，层级替代一律判失败。

| 层级 | 测什么 | mock 边界 | 必须真连 | 证据形态 |
|---|---|---|---|---|
| L0 单元 | 单函数/单组件逻辑 | 全部依赖可 mock | — | 测试输出 + 退出码 |
| L1 契约 | 双端 schema 一致、字段漂移 | 后端 mock 数据须来自真实响应样本 | schema 生成链路 | 生成器输出 + 漂移门禁结果 |
| L2 集成 | 同机真实前后端调用 | 设备/硬件可 mock | 真实后端进程 | 真实请求/响应 + 版本号 |
| L3 端到端 | 浏览器或客户端完整链路 | 不允许 mock 后端 | 真服务 + 真构建产物 | 浏览器操作记录 + 截图/网络面板 |
| L4 物理/设备 | 声音、灯、电机、真实硬件 | 不允许任何 mock | 真设备 | 人耳/仪器/传感器观测记录 |

## 填写规则

- 每条验收标准必须注明它需要的最低证据层级。
- mock 只出现在 L0-L1；L2 起后端必须真实运行。
- L4 结论不允许由软件状态推断：日志安静 ≠ 声音正常，状态 ACTIVE ≠ 物理在播。
- 强制触发路径：失败/边缘分支必须有强制触发手段（配置开关或测试钩子），否则该分支视为未测。

## 示例

| 验收点 | 最低层 | 说明 |
|---|---|---|
| 接口字段与生成 schema 一致 | L1 | 漂移门禁红灯演示 |
| 按钮点击后界面显示「已停止 N 条播报」 | L3 | 浏览器实测，禁止只跑组件测试 |
| 音响真的停止发声 | L4 | 人耳或录音确认；API 返回成功不算 |
